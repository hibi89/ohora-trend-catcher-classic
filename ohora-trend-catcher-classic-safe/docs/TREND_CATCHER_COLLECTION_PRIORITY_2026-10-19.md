# OHORA Trend Catcher — 수집 목표 및 운영 우선순위 (2026-10-19)

## 최상위 목표
- **1차 목표: 공식 294개 계정의 최근 1년치 게시물 데이터를 가능한 한 확보한다.**
- **실질적 핵심: 최신 게시물을 지속적으로 수집·누적하여 시간에 따른 디자인 트렌드 변화, 상승·하락 신호, 국가별 차이 등 유의미한 인사이트를 찾는다.**
- 1년치 완전 수집이 어려워도 가능한 범위까지 과거 데이터를 확보하고, **최신 데이터 축적을 중단하거나 지연시키지 않는다.**
- 트렌드캐쳐의 성패를 과거 1년치 완결 여부 하나로 판정하지 않는다.

## 실행 우선순위
1. **최신 수집(Front) 안정성:** 공식 계정 목록을 기준으로 정기적으로 최신 게시물을 수집하고, 중복을 방지하며, 요청 성공·실패와 차단 계정을 추적한다.
2. **시간별 누적 데이터 품질:** 게시물의 게시 시각과 수집/관측 시각을 구분해 보존하고, 반복 관측값을 축적한다. 수집 범위와 누락 가능성을 기록한다.
3. **인사이트 도출:** 국가·기간·디자인 속성별 추이, 신규 등장 및 상승 신호, 참여도 변화 등을 분석한다. 팔로워 규모와 관측 기간 차이 등 비교 편향을 표시한다.
4. **History 보강:** 최신 수집에 영향을 주지 않는 API 여유 범위에서 과거 1년치를 우선적으로 역수집한다. 1년 완결이 불가능하면 확보된 범위를 명시하고 계속 축적한다.
5. **증거 기반 감사:** 원본 응답·DB·커서 체인·실제 수집 범위를 구분하여 검증한다. 미검증 과거 완결성은 완료로 표시하지 않는다.

## 현재 확인된 상태 (2026-10-19 시점)
- 공식 계정 294개 중 최신 조회 성공 286개, Meta API 오류로 차단된 계정 8개.
- 저장 게시물 1,270개, 게시물 관측 1,290건.
- 원본 JSON 대비 게시물·관측값 검사 PASS, 캐러셀/미디어 검사 PASS (오류 0, 경고 0).
- 기존 10계정은 `backfill_done=1`이지만 역사적 완료 증거 체인이 미검증 상태. Front 원본 커서와 DB 커서가 10/10 일치하나 실제 복구는 미완료.
- 286계정의 누적 `media_count` 합계는 748,123건. 이는 **1년치 게시물 수가 아니며**, 연간 수집량 추정치는 가정일 뿐이다.
- History 5계정 시험은 쿨타임으로 아직 API 호출이 실행되지 않았다.

## 운영·검증 원칙
- 최신 수집이 History 수집보다 우선한다. 단, 기존 스케줄러 정책이 이를 실제로 보장하는지는 별도 확인·검증한다.
- 저장된 게시물의 일치성과 인스타그램 전체 게시물 수집의 완결성은 서로 다른 개념이다.
- 1년치 미달을 실패로 처리하지 않는다. **관측 가능한 최신 데이터의 지속적 누적과 신뢰할 수 있는 변화 추이 분석**을 핵심 성과로 본다.
- 쿨타임, API 사용량, 원본 보존, DB 백업, 중복 방지, 커서 무결성은 유지한다.
- 이 문서는 목표·우선순위의 기록이며, 스케줄러 코드나 수집 설정을 변경하지 않는다.
